# JavaScript Cơ Bản

Dưới đây là các file JavaScript cơ bản, mỗi phần riêng một file.

## Các file có sẵn
- `hello-world.js`
- `variables.js`
- `if.js`
- `if-else-if.js`
- `while.js`
- `do-while.js`
- `for.js`
- `switch.js`
- `functions.js`
- `arrays.js`
- `objects.js`
- `index.js`

## Chạy ví dụ
```bash
node hello-world.js
```
